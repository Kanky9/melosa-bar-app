# **App Name**: Melosa Bar App

## Core Features:

- Public Catalog View: Display a public catalog with product categories (drinks, food, etc.)
- Category Management: Admin area to create/edit/delete categories.
- Product Management: Admin area to add products with title and price.

## Style Guidelines:

- Primary color: Yellow (#FFDA63) for highlighting main content and actions.
- Secondary color: Black (#000000) for text and borders.
- Accent: Dark Yellow (#F2D730) for interactive elements.
- Clean and readable font for product titles and descriptions.
- Grid-based layout for product catalog to showcase items effectively.
- Simple, minimalist icons for category navigation and admin functions.
